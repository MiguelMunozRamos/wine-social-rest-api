# Wine Social REST API

REST API developed in Java using Jersey/JAX-RS for managing users, wines, followers and wine recommendations.

## Description

This project implements a REST API for a small wine social network. It allows users to register, manage wines, follow other users and receive wine recommendations.

The project also includes a Java client that consumes the REST API using HTTP requests and JSON.

## Technologies

- Java
- Jersey / JAX-RS
- JSON
- Apache Tomcat
- REST API
- WAR deployment
